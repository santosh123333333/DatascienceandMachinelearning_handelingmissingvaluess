# Data Science & Machine Learning — Handling Missing Values & Data Cleaning

A Jupyter Notebook demonstrating practical techniques for **handling missing values**
and **cleaning raw data** using Python (pandas, NumPy).

## 📌 What this notebook covers

- Detecting missing values (`isnull`, `isna`, `info`)
- Dropping missing data (`dropna`)
- Filling missing values (`fillna` with mean / median / mode / constant)
- Forward & backward fill (`ffill`, `bfill`)
- Interpolation
- Handling duplicate rows
- Data type conversion and basic cleaning steps

## 🛠️ Requirements

- Python 3.8+
- Jupyter Notebook / JupyterLab
- pandas
- numpy

Install the dependencies:
pip install pandas numpy jupyter
